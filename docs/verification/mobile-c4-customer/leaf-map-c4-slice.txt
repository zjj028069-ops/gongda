- **消息栏**：不「吃掉」PC「消息中心」叶子——那些叶子仍在功能栏菜单树保留；消息栏是壳级会话/任务卡入口。

## 2. 相对旧设想变化点

相对《手机端全量镜像开发计划》旧四栏 **「聊天｜联系人｜功能｜我」**，以及「消息中心/系统管理全塞功能」的写法，本表按新四栏调整如下：

1. **聊天 → 消息**：底栏文案与职责改为「消息」（人/agent/群/系统消息 + 任务卡），不再叫「聊天」。
2. **我 → 设置**：原「我」里偏配置的部分升级为独立「设置」栏（企业设置 + 用户设置）；个人中心/帐套进入设置而非含糊的「我」。
3. **搜索分栏隔离**：旧设想顶栏共用放大镜、域界不清；现明确四栏各自搜索域，消息搜不出菜单、功能搜不出消息。
4. **加号壳级收拢**：PC 散落「新增 / 从某某创建」统一到右上角加号＋下拉；单据链不丢。
5. **消息中心双入口**：壳「消息」= 会话入口；功能·消息中心·消息列表叶子仍保留（不删、不吞）。
6. **客户/供应商/用户双入口**：联系人栏快捷档案 + 功能树原路径仍在。
7. **系统管理设置项双入口**：企业信息/通用/短信/编号/个人中心 → 设置栏 + 功能树。
8. **一级数量口径**：旧文口语「14 一级」更正为现网 **15**（含「智能设备」）。
9. **报价合同不可藏**：旧波次仅写「客户管理镜像」未点名；现硬约束合同报价单 **必留全操作**，禁止隐藏/不上/占位。
10. **销售合同加号选上游报价**：合同订单加号必须含「报价单创建」；销售合同←报价合同链路显式入表，禁止只留空白新增。
