# 平台运营后台与固定双管理员验收

更新：2026-10-26。工程0.5.0-dev.1运营后台增补。本轮依据用户新增要求实现，独立于快工单企业端规则，不假称已观察到参考产品的平台管理员后台。

## 入口与身份

- 平台后台：`http://127.0.0.1:5173/platform-admin`。
- 企业工作空间：`http://127.0.0.1:5173/`。
- 平台运营账号固定两个：`platform.owner`、`platform.ops`，两者具有相同的平台运营权限，操作记录区分实际操作人。
- 两个账号均已在本机数据库创建，独立随机密码仅写入被Git忽略的 `.local/platform-admin-credentials.txt`。没有公开上传，没有将明文写入数据库或日志；原先第一个账号密码保持不变。
- 企业管理员使用企业标识与企业账号登录，与两个平台账号分开。企业管理员数量不占平台固定名额。

平台登录页、企业登录页及企业工作区页脚均有对应入口。企业内“组织与权限”继续负责本企业组织、成员及角色；企业空间页只切换已加入企业，新企业开通跳转平台后台。

## 已实现能力

|能力|实际行为|
|---|---|
|独立认证|独立账号表、会话表、Cookie和CSRF；企业Cookie不能访问平台接口，平台Cookie本身不能进入企业业务接口|
|企业目录|全部企业搜索、分页，启用／停用和总数统计；显示启用成员及有效管理员数量，不读取客户业务订单|
|开通企业|同一事务写企业、企业专属初始管理员、成员资格、显示资料、个／米／张单位、默认资源配额和平台审计；无其他企业业务复制|
|重试保护|开通请求标识重复返回同一企业，不重复创建；相同标识改变公开开通内容被拒绝。重试不会覆盖既有密码|
|启停企业|版本校验及原因记录；停用时清除该企业全部会话，禁止登录和旧会话访问；恢复也不复活旧会话；保留业务数据|
|管理员维护|为指定企业增补独立管理员，启停成员资格，保护最后一位有效管理员；与企业内部账号维护共享串行锁及版本变更|
|密码重置|企业专属管理员重置后旧密码及全部旧会话失效；原因入审计，不记录新密码；历史多企业共享身份禁止此处重置，以免影响其他企业|
|操作记录|平台登录退出、企业开通变更、管理员新增启停及密码重置；记录实际平台账号、时间、对象和原因；运行角色不能改删记录|
|固定两账号|只展示固定两席位，无新增删除平台账号入口；没有公开平台账号注册API|

## 有且只能两个的约束

用户明确限定平台运营管理员为两个。017迁移给平台账号增加固定席位1／2，非空、唯一且只接受1或2，数据库不能插入第三席位或重复占席位。

延迟约束触发器在事务提交时要求成对保留，阻止删除一个或全部；TRUNCATE另有触发器拒绝。运行角色没有运营账号新增、改动或删除权限。启动安全检查核对固定席位约束和两个触发器。空的新安装数据库仅能先运行成对初始化，平台登录在未有两个账号时拒绝；本机已完成初始化，当前确为两个。

`npm run control:setup`只补齐缺失席位，不覆盖已有账号或密码；重复执行已验证密码文件不变。生产初始化需在安全环境设置首个账号的 `CONTROL_ADMIN_USERNAME`／`CONTROL_ADMIN_PASSWORD`，第二个账号的 `CONTROL_ADMIN_SECOND_USERNAME`／`CONTROL_ADMIN_SECOND_PASSWORD`，密码至少12字符；不得使用开发随机凭据。平台账号换人或遗失密码需受控运维流程，本轮未开放运营账号网页重置、改名和新增入口。

## 数据库与权限变更

新增016和017迁移，已应用001—015不改写。016引入独立 `gd_control` NOLOGIN、NOINHERIT、NOBYPASSRLS角色及全局运营表；原 `gd_platform`仍仅服务企业内成员维护，不能当成全平台运营权限。

`gd_control`可管理企业目录和身份归属，不能读企业产品表或企业用户密码哈希；不能改删平台审计。新企业初始化仅在授权的运营事务内切换至既有企业角色、设置新企业上下文初始化资料，随后切回运营角色。原业务RLS保留；企业成员表增加只属于gd_control的全局运营策略，启动校验同步检查，普通企业角色策略没有放宽。

生产受限数据库运行账号需额外被授予gd_control角色切换资格，仍不能是超级用户、BYPASSRLS、迁移／业务／身份表所有者。独立PostgreSQL实际部署、MFA、部署域名隔离、监控和灾备仍属于后续生产验收。

本机升级前服务已退出，分别保存：

- `.local/control-console-before-20261026-201452/database`：运营后台升级前数据库。
- `.local/control-before-fixed-pair-20261026-202331/database`：固定双账号迁移前数据库。

备份包含私密数据，不提交。恢复须配套代码与迁移版本，不可把旧数据库直接交给新服务自动升级当作已完成回退演练。
